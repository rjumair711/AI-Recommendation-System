# 🎬 AI Movie Recommendation System

## 📌 Project Overview

This project is an AI-powered Movie Recommendation System built using Python and Machine Learning concepts.

The system recommends movies based on user interests using:

- TF-IDF Vectorization
- Cosine Similarity
- Content-Based Filtering

Users can enter movie interests such as:

space AI future

and receive intelligent movie recommendations.
